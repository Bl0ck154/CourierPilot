# CourierPilot 0.14.7

## Route Research map

- Replaces the old geometry-only grid with an interactive OpenStreetMap basemap.
- Pedestrian and cycleway Valhalla routes are drawn together on the real street map.
- Start and finish are marked explicitly.
- The map automatically fits both route candidates after every comparison.
- Drag and pinch-zoom are enabled so detours and shortcuts can be inspected against actual streets.
- OpenStreetMap attribution is shown on the map.
- Route overlays still come from the self-hosted Valhalla backend; only map tiles are fetched externally.
